# Infraestructura

Proyecto de **redes y cableado estructurado** para una fábrica de 4 pisos: diseño lógico en Packet Tracer, planos físicos en SketchUp y documentación técnica completa (cableado, subredes, equipos).

## Contenido

| Recurso | Descripción |
|---|---|
| `Red.pkt` | Topología de red (Packet Tracer) |
| `EXCEL EMPRESA.xlsx` | Documentación técnica: pisos, DTC/rack 12U, backbone, subredes, sucursal |
| `planos-sketchup-v1` | 5 planos SketchUp (~1 GB) — [assets de la release](https://github.com/estivenchaluisa27-ops/Infraestructura/releases/tag/planos-sketchup-v1) |
